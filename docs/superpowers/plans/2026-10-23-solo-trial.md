# Пробная игра и домашняя подготовка — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Папка `пробная/` с одиночной пробной игрой (сценарий, пробный герой, карточки предметов), домашним опросником «Какой ты герой?» и гайдом для родителей, плюс сборка PDF.

**Architecture:** Контент — markdown на русском, собирается в HTML/PDF тем же способом, что корневой `build.sh` (pandoc + headless Chrome, общий `../print.css`). Сценарий и карточки связаны номерами карточек `П1…П12`. Опросник проверяется скриптом на равномерность героев.

**Tech Stack:** Markdown, pandoc, Google Chrome headless, bash, python3 (только для проверки опросника).

**Spec:** `docs/superpowers/specs/2026-10-23-solo-trial-design.md`

## Global Constraints

- Механика строго из `правила.md`: d20, **10 и больше** — успех, **20** — супер-успех ⭐, **1** — смешная неудача 🍌, талант = бросить 2 раза и взять большее, 5 ❤️, зелье +2 ❤️ (не больше 5).
- Всё для детей, родителей и ведущего во время игры — на русском; `пробная/печать.md` — на английском, как корневой `печать.md`.
- Стиль как в существующих файлах: эмодзи, коротко, крупно, примечания ведущему — цитатой `> **Для ведущего.** …`, разрыв страницы `<div style="page-break-after: always;"></div>`.
- Без Звездочёта, его башни, кота Мурлыки, Бурчуна, кристалла, шифра СВЕТ и немецких слов из основной игры.
- В комнате невозможно проиграть: неудача — «да, но…».
- Проект не в git — шагов commit нет.

## Review Focus

1. Ребёнок предлагает решение, которого нет в сценарии → в сценарии есть явное правило «соглашайся, назначь бросок по подходящему умению».
2. Ребёнок проваливает бросок несколько раз подряд → у каждого препятствия есть «да, но…» и другой путь; после 2 неудач на одном месте — подсказка попугая Кеши.
3. Ребёнок выбросил 1 при 1 ❤️ → герой не «выбывает»: сердечки не опускаются ниже 1 в пробной игре (правило в сценарии).
4. Ничья в опроснике (3 и более героя с равным счётом, или ничья за второе место) → правило ничьей покрывает оба случая.
5. Ребёнок не умеет читать бегло → тексты на карточках ≤ 6 слов крупно, опросник читает родитель.

## Решения, общие для задач

**Сеттинг (П = пробная):** Гильдия героев Солнечной долины. Старый добрый рыцарь **сэр Пончик** испытывает нового **героя-ученика**: в **Комнате испытаний** нужно открыть запертый **сундук**, в котором лежит **Значок героя**. В комнате живёт болтливый **попугай Кеша** — он же даёт подсказки.

**Умения пробного героя:** 💪 **Сила**, 🤸 **Ловкость**, 🧠 **Смекалка**. Одно из них — талант.

**Места и пути к цели:**

| Место | Карточка | Что там | Бросок |
|---|---|---|---|
| Сундук (цель) | П1 | Старый замок | Открыть: 💪 поднять/сорвать крышку · 🤸 открыть отмычкой (П7) · 🔑 ключом (П6) — без броска |
| Высокий шкаф | П2 | Наверху блестит ключ П6 | 🤸 залезть · 💪 подвинуть стол и встать · 🧠 сбить метлой/придумать |
| Стол с ящиком | П3 | Отмычка П7, печенье П8, зелье П9 | Ящик заело: 💪 дёрнуть (или без броска, если ребёнок догадается потянуть мягко) |
| Попугай Кеша | П4 | Знает, где ключ; загадка | 🧠 отгадать загадку (на карточке) **или** угостить печеньем П8 — без броска |
| Полка с банкой муки | П5 | Ловушка: банка падает | Если ребёнок трогает полку — 🤸 увернуться; неудача = −1 ❤️ и герой весь в муке 😄 |

**Карточки `пробная/карточки.md`:**

| № | Название |
|---|---|
| П1 | Сундук с замком |
| П2 | Высокий шкаф |
| П3 | Стол с ящиком |
| П4 | Попугай Кеша + загадка |
| П5 | Полка с банкой муки |
| П6 | Ключ |
| П7 | Отмычка |
| П8 | Печенье |
| П9 | Зелье (+2 ❤️) |
| П10 | «Как открыть сундук?» — 💪 · 🤸 · 🔑 · ❓ «твоя идея» (выкладывается в начале, показывает вариативность) |
| П11 | Предметы героя на выбор: 🪢 верёвка · 🔦 фонарик · 🍪 печенье (3 на странице) |
| П12 | Значок героя-ученика (награда, имя вписать) |

### Task 1: Пробный герой и карточки

**Files:**
- Create: `пробная/герой.md`
- Create: `пробная/карточки.md`

**Interfaces:**
- Produces: номера и названия карточек П1–П12 (таблица выше); умения 💪 Сила / 🤸 Ловкость / 🧠 Смекалка; предметы героя 🪢 / 🔦 / 🍪.

- [ ] **Step 1: Написать `герой.md`**

Страница 1 — мини-опросник для ведущего (3 вопроса, читать вслух):
1. «Что тебе больше нравится: поднять самое тяжёлое 💪, залезть выше всех 🤸 или отгадать загадку 🧠?» → **талант**.
2. «Что ты возьмёшь в приключение: верёвку 🪢, фонарик 🔦 или печенье 🍪?» → предмет (карточка П11).
3. «Как зовут твоего героя? Какой он?» → имя, рисунок.

Страница 2 — карточка героя-ученика в формате карточек `персонажи.md`: имя ____, «Кто я: Я герой-ученик из Гильдии героев», сердечки ❤️×5, три умения с ☐ «мой талант (бросаю 2 раза)» — ребёнок отмечает один, «Мой предмет: ____», рамка «Нарисуй своего героя». Без суперсилы.

- [ ] **Step 2: Написать `карточки.md`**

Шапка `> **Для ведущего.** …` как в корневом `карточки.md`, затем П1–П12, каждая с новой страницы, заголовок `## Карточка П1 · Сундук с замком`. На карточках — крупные эмодзи и не больше 6 слов текста. П4 содержит загадку для 6–8 лет с отгадкой, которую можно найти в комнате (например, ключ), отгадку не печатать на карточке.

- [ ] **Step 3: Проверить**

Run: `grep -c '^## Карточка П' пробная/карточки.md`
Expected: `12`
Run: `grep -nE 'Звездочёт|Мурлык|Бурчун|кристалл' пробная/*.md`
Expected: пусто.

### Task 2: Сценарий пробной игры

**Files:**
- Create: `пробная/сценарий.md`

**Interfaces:**
- Consumes: карточки П1–П12, умения и предметы из Task 1.

- [ ] **Step 1: Написать `сценарий.md`**

Разделы:
1. Шапка: 1 ребёнок 6–8 лет, первый раз, 15–25 минут, d20, «10 и больше — успех».
2. Подготовка (5 минут): что распечатать, разложить П1–П5 лицом вверх, П6–П9 у себя.
3. Как вести — 5 советов (адаптировать из корневого сценария: спрашивай «Что ты делаешь?», бросок только когда интересно, «да, но…», хвали идеи, **любая разумная идея ребёнка — назначь бросок по подходящему умению**).
4. Сцена 0. Создаём героя (`герой.md`) + пробный бросок. Фраза на случай, если ребёнок уже знает своего героя: «Сегодня ты тренируешься с героем-учеником, а твой настоящий герой ждёт тебя на большой игре».
5. Сцена 1. Комната испытаний: текст сэра Пончика вслух (цитатой), выложить П10 и сказать: «Сундук можно открыть по-разному. Как ты думаешь?»
6. Места П1–П5 по таблице «Места и пути» — для каждого: что видит ребёнок, броски, что при успехе, «да, но…» при неудаче, что при 20 и при 1.
7. Подсказки Кеши: по одной на каждое место; правило «2 неудачи на одном месте → подсказка».
8. Правило сердечек для пробы: −1 ❤️ только в ловушке П5 (и при 1 по решению ведущего), ниже 1 ❤️ не опускается; зелье П9 возвращает +2.
9. Финал: Значок П12, ведущий перечисляет, что ребёнок уже умеет (бросок, талант, сердечки, своя идея), и отдаёт опросник + гайд родителям.
10. Раздел «Для ведущего: как раздать героев на большую игру» — по спецификации: собрать от родителей по 2 героя, раздать без повторов (основного, иначе запасного); если двое очень хотят одного — можно, «двое из одного ордена» с разными именами/питомцами/предметами; на игре выдать каждому его карточку.

### Task 3: Домашний опросник

**Files:**
- Create: `пробная/опросник.md`
- Create: `пробная/check_quiz.py`

**Interfaces:**
- Produces: формат строки ответа (для скрипта): `- ⬜ <текст ответа> → <эмодзи1> <эмодзи2>`; эмодзи героев: `⚔️ ✨ 🏹 🌿 🐾 🎵 🗝️ 🔨` (как в `персонажи.md`).

- [ ] **Step 1: Написать `check_quiz.py`**

`python3 пробная/check_quiz.py пробная/опросник.md` — разбивает файл на вопросы по заголовкам `### Вопрос N`, в каждом собирает строки ответов по формату выше, сравнивает эмодзи без учёта variation selector `️`. Проверяет: ровно 6 вопросов; в каждом 4 ответа; в каждом вопросе каждый из 8 героев встречается ровно 1 раз; ни одна пара героев не повторяется в двух вопросах. Печатает `OK` и выходит с 0, иначе печатает ошибку и выходит с 1.

- [ ] **Step 2: Запустить на пустом/отсутствующем опроснике**

Run: `python3 пробная/check_quiz.py пробная/опросник.md`
Expected: ошибка, код 1.

- [ ] **Step 3: Написать `опросник.md`**

Страница 1: обращение к ребёнку («Ответь на 6 вопросов и узнай, какой ты герой!») и короткая инструкция для родителя (читать вслух, отмечать один ответ).
Страницы вопросов: 6 вопросов про предпочтения ребёнка (что любишь делать, что возьмёшь в поход, какое животное, что делаешь, если друг грустит, и т.п.), у каждого 4 ответа с эмодзи-картинкой, по формату строки выше.
Таблица подсчёта: 8 героев (эмодзи + название), клетки для палочек.
Правило результата: больше всего палочек — «мой герой», следующий — «мой запасной герой». Ничья: если наверху двое — ребёнок сам выбирает главного по описаниям, второй становится запасным; если ничья за второе место — ребёнок выбирает запасного из них.
Страница результатов: 8 героев, по 2–3 строки каждый (кто он, талант, суперсила — по `персонажи.md`), и поле «Мой герой: ____ · Мой запасной герой: ____».

- [ ] **Step 4: Запустить проверку**

Run: `python3 пробная/check_quiz.py пробная/опросник.md`
Expected: `OK`
